# 2026 世界杯赛程与朋友竞猜

这是一个面向朋友小范围使用的 2026 FIFA 世界杯静态页面项目。

页面包含完整赛程、意大利时间与中国时间、FIFA 世界排名、强队阵容、比赛看点、收看渠道、虚拟币竞猜与实时排行榜。项目部署在 GitHub Pages，竞猜数据通过云端同步，适合 11 位朋友一起看球、竞猜和追榜。

## 在线访问

访问地址：

```text
https://wugeiwa-prog.github.io/fifa-world-cup-2026/
```

访问密码请向组织者获取。

## 主要功能

- 2026 世界杯 104 场赛程
- 意大利时间 CEST 与中国时间 CST 对照
- 比赛结果、已完成场次与剩余场次进度
- 国旗、中文队名、英文三字码与 FIFA 世界排名小标
- 重要赛事与比赛看点标注
- 48 支参赛队 FIFA 世界排名
- 12 个小组信息
- 热门强队阵容摘要
- 中国大陆与意大利收看渠道说明
- 11 人虚拟币竞猜系统
- 实时余额榜与每日涨跌记录

## 竞猜规则

- 最多 11 名玩家参与。
- 每人初始 1000 虚拟币。
- 仅开放意大利时间今天和明天、且对阵已确定的未完赛比赛。
- 支持「胜平负」和「猜比分」。
- 单注下限 10 虚拟币。
- 单注上限为当前余额的 50%。
- 比赛结束后，写入官方比分即可自动结算相关竞猜。
- 竞猜仅供朋友间娱乐，无真实货币。

## 数据说明

- 赛程、比分、球队与阵容信息优先依据 FIFA 官方页面整理。
- 世界排名依据 FIFA/Coca-Cola 男足世界排名。
- 赔率优先使用已收集到的赛前盘口快照；缺少盘口时，回退到基于 FIFA 世界排名的泊松模型估算。
- 页面为静态快照，不自动抓取 FIFA 或盘口网站；后续结果需要维护者手动核对并写入页面数据。

## 技术说明

- 单文件静态页面：`world-cup-2026-schedule.html`
- 根入口跳转页：`index.html`
- GitHub Pages 部署
- 云端同步用于公开昵称、虚拟币余额、投注记录和榜单
- 密码校验信息仅保存在当前设备
